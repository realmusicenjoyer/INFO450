# INFO 450: Senior Design Project / Advanced Software Development
**School of Business — Department of Information Systems**  
**Virginia Commonwealth University (VCU)**

---

## 📌 Course Overview
INFO 450 serves as a capstone experience for Information Systems students at VCU. The course focuses on synthesizing modern software development methodologies, systems analysis, database design, and cloud technologies to design, build, and deploy an end-to-end enterprise software solution.

---

## 🛠 Tech Stack & Tools

* **Frontend:** React / HTML5 / CSS3 / JavaScript
* **Backend:** Node.js (Express) / Python (Django/FastAPI)
* **Database:** PostgreSQL / MySQL / MongoDB
* **Version Control & CI/CD:** Git, GitHub Actions
* **Deployment / Cloud:** AWS / Heroku / Vercel

## 🚀 Key Learning Objectives & Deliverables

* **Agile Software Development:** Iterative development sprints, backlog grooming, and stand-ups.
* **Full-Stack Application Development:** Architectural design, API development, and client-side integration.
* **Database Modeling & Implementation:** Designing normalized relational schemas and optimizing query performance.
* **Project Management & Documentation:** User stories, system architecture diagrams, and deployment strategies.
